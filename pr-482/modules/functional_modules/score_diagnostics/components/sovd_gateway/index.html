Abstract#

The S-CORE SOVD gateway (//score/opensovd-core:opensovd-gateway) is the single SOVD entry point of a system. It is built on Eclipse OpenSOVD Core: it hosts the entities of the S-CORE platform itself and forwards everything else to an upstream SOVD server, such as the classic diagnostic adapter for UDS ECUs. Data of its own entities comes from the UDS data bridge.

Motivation and Rationale#

Testers need one SOVD API for the whole vehicle instead of one per network domain or protocol (SOVD Gateway (feat_req__diagnostics__sovd_gateway)).

Specification#

The requirements describe only what this component adds on top of ISO 17978 (SOVD). Resources, methods, payload formats and error responses of the SOVD API itself are defined by the standard (SOVD Standard (feat_req__diagnostics__sovd_std)) and are not repeated here.

OpenSOVD Core, on which this gateway is built, offers these options:

  • Upstreams: any number of upstream SOVD servers, each reached over HTTP on TCP or a Unix domain socket.

  • Authentication: can be enabled.

  • Service discovery: the gateway can announce itself via mDNS.

Open v1.0 work items are tracked in eclipse-score/inc_diagnostics#66.
