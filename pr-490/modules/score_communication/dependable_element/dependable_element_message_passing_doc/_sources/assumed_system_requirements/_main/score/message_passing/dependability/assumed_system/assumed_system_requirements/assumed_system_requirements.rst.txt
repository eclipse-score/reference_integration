Assumed System Requirements
===========================
.. requirement:definition:: MessagePassing.ClientServerCommunicationModel

   The system shall provide a mechanism for two application processes to communicate as a client and a server across process boundaries: a server process accepts connections addressed to a named service, and a client process initiates a connection to that named service.

.. requirement:definition:: MessagePassing.PointToPointConnectionTopology

   Each connection the system establishes between a client and a server shall connect exactly one client endpoint to exactly one server endpoint for the connection's entire lifetime.

.. requirement:definition:: MessagePassing.RequestReplyInteractionCapability

   The system shall support a request-reply interaction, in which a request sent to a server yields a corresponding reply from that server as part of the same interaction.

.. requirement:definition:: MessagePassing.OneWayMessageDeliveryCapability

   The system shall support delivering a message from either end of a connection to the other without the sender waiting for or expecting a reply.

.. requirement:definition:: MessagePassing.RuntimeFailureDetectability

   The system shall provide the communicating application with the means to determine, during operation, that a communication attempt has failed rather than succeeded.

.. requirement:definition:: MessagePassing.IntegrationMisconfigurationDetectability

   The system shall provide the means to detect, when a client and a server first attempt to communicate, that they have been configured with incompatible communication parameters.

.. requirement:definition:: MessagePassing.PlatformAbstraction

   The system shall provide its client-server communication API in a form usable across more than one host operating system, to support development, evaluation, and testing convenience, and deployment in non-safety (QM) contexts on platforms other than the certified safety target.

.. requirement:definition:: MessagePassing.QnxAsilBQualifiedImplementation

   On QNX, the system's certified safety target platform, the common client-server API, its shared abstraction code, and the underlying transport implementation shall be capable of ASIL B qualification.

.. requirement:definition:: MessagePassing.PeerIdentityInformationForAccessControl

   The system shall provide the server with information identifying the connecting client, sufficient to support the integrator's own authentication and/or access-control decisions.
