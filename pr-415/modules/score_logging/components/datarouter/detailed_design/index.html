Description#

The Datarouter (Datarouter (comp__datarouter)) is the DLT daemon. It reads the log records of the clients from shared memory, filters them, and sends them as DLT messages over UDP multicast. A client (mw::log) connects through a message passing channel. The Datarouter asks the client to hand over a buffer by a notification and reads it from the shared memory. It never blocks on a client.

The design documents and PlantUML diagrams are in score/datarouter/doc/design. This folder links them by symbolic links, so that the files stay at their place in the source tree. The source code is in score/datarouter. Paths in this document are relative to this directory unless noted otherwise.
