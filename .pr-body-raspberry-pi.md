## Summary

Add Raspberry Pi 4B disk images for EB corbos Linux for Safety Applications
and Raspberry Pi OS Lite, with the platform, showcases and diagnostics.

- Deploy the image payload without booting the base image.
- Configure a static IPv4 address at build time.
- Lock empty passwords and restrict the development gateway to loopback.
- Add image preparation and deployment tests to internal CI.

This draft is stacked on #482, which provides the diagnostics integration.
The images are for integration testing, not production. Provision unique
credentials and remove any bundled development keys before remote access.
